# Finora

A personal finance tracker — log expenses, track income, set budgets and savings goals, and see insights.

## Stack

- **Frontend** — React (Vite), custom CSS design system
- **Backend** — Express + MongoDB (Mongoose) + JWT auth
- **Email** — Resend (for password resets)

## Features

- 🔐 Email + password auth with rate-limited name changes
- 💸 Expense tracking (categories + payment methods)
- 💰 Income tracking (multiple sources)
- 🎯 Budgets (weekly / monthly / yearly)
- 🏆 Savings goals with progress and add-savings
- 📊 Insights: category breakdown, weekly chart, income vs expense
- 🌙 Light / Dark / System theme
- 🔒 Private View — mask all amounts with one toggle
- 📥 Export all data to Excel (.xlsx)
- 🛡️ Admin panel — promote / demote / delete users
- 🔔 In-app notifications
- 📱 Fully responsive (mobile + desktop)
