# Finora

A personal finance tracker. Log your expenses and income, set budgets, create savings goals, and see where your money is going.

Built as a full-stack project with a React frontend and an Express/MongoDB backend.

## What it does

- Sign up and log in with email and password
- Record expenses with category, payment method, date, and note
- Record income from different sources
- Set weekly, monthly, or yearly budgets per category
- Create savings goals and add to them over time
- View insights: category breakdown, weekly spending, income vs expenses
- Toggle between light, dark, and system themes
- Toggle Private View to hide all amounts on screen
- Export everything to an Excel file
- Admin users can manage other accounts
- In-app notifications

## Tech stack

Frontend: React with Vite, plain CSS with design tokens
Backend: Node.js, Express, MongoDB with Mongoose
Auth: JWT tokens
Email: Resend for password reset links
